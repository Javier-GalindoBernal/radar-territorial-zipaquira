# Versión para la Alcaldía de Zipaquirá

Ruta publicada prevista: /alcaldia.html. Guía propia: /guia-alcaldia.html. Se conservan el motor, cartografía, filtros, demo, almacenamiento local y créditos del desarrollo.

Lema solicitado: Zipaquirá Cree, Protege y Avanza 2024-2028. La denominación con 2028 figura en el artículo 1 del Acuerdo 02 de 2024 publicado por EPZ, página 6: https://epz.gov.co/wp/wp-content/uploads/2024/07/ACUERDO-02-COMPLETO.pdf#page=6 . Es una comprobación del rótulo textual del PDM, no del período jurídico de mandato del alcalde.

Imagen original aportada por el usuario, preservada sin edición en Inputs del proyecto y copiada a dist/assets/alcaldia-zipaquira.jpeg. La interfaz indica Prototipo y mantiene el aviso de datos sintéticos; no acredita adopción institucional.

Al usar el mismo dominio y motor, ambas interfaces comparten los registros guardados en el navegador. La simulación permanece separada y sin guardado o exportación. No se trasladaron datos reales ni se creó una base institucional.

La nueva ruta no depende de una conexión de Facebook, cuentas externas o servicios nuevos.
